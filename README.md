# Авторазборка23

Статический сайт авторазборки: каталог б/у автозапчастей, карточка товара, информационная страница.
Без сборки и зависимостей — чистые HTML, CSS и JavaScript.

## Структура

```
├── index.html          # Главная: интерактивная схема авто, поиск, категории
├── catalog.html        # Каталог: фильтры, сортировка, grid/list-режимы
├── product.html        # Карточка товара: галерея, табы, похожие детали
├── about.html          # О компании: типографика, таблица, форма обратной связи
│
├── css/
│   ├── styles.css      # Дизайн-система: токены, кнопки, шапка, подвал, карточки
│   ├── home.css        # Стили главной
│   ├── catalog.css     # Стили каталога
│   └── product.css     # Стили карточки товара
│
├── js/
│   ├── main.js         # Общее: шапка, бургер-меню, подбор запчасти, скролл
│   ├── home.js         # Интерактивная схема автомобиля
│   ├── catalog.js      # Фильтрация, сортировка, переключение вида
│   ├── product.js      # Галерея, табы
│   └── about.js        # Форма обратной связи
│
├── images/
│   └── car-photo.png
│
└── design/             # Исходные макеты (.dc.html) — в сайте не используются
```

## Дизайн-система

Токены объявлены в `:root` внутри `css/styles.css`:

| Переменная | Значение | Назначение |
|---|---|---|
| `--blue` | `#1e5cff` | Акцент, ссылки, активные состояния |
| `--orange` | `#ff6a1a` | Целевые действия (CTA) |
| `--dark` | `#0b1730` | Заголовки, подвал |
| `--text` / `--muted` / `--subtle` | — | Три уровня текста |
| `--font` / `--font-d` / `--font-m` | Manrope / Space Grotesk / JetBrains Mono | Текст / заголовки / моноширинный |
| `--nav-h` | `72px` | Высота шапки (нужна для `sticky`-блоков) |

Контент ограничен шириной `1440px`, есть брейкпойнты на `768px` (мобильный),
`769–1024px` (планшет) и `1440px+` (широкий экран).

## Локальный запуск

Сборка не нужна — достаточно любого статического сервера:

```bash
python3 -m http.server 3456
```

Затем открыть <http://localhost:3456>.

## Публикация на GitHub Pages

1. Создать репозиторий и запушить содержимое папки.
2. В репозитории: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` в корне отключает обработку Jekyll — статика отдаётся как есть.
