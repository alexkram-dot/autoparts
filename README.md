# Авторазборка23

Статический сайт авторазборки: каталог б/у автозапчастей, карточка товара, информационная страница.
Без сборки и зависимостей — чистые HTML, CSS и JavaScript.

## Структура

```
├── index.html          # Главная: интерактивная схема авто, поиск, категории
├── catalog.html        # Каталог: фильтры, сортировка, grid/list-режимы
├── product.html        # Карточка товара: галерея, табы, похожие детали
├── about.html          # О компании: цифры, путь детали, принципы, реквизиты
├── reviews.html        # Отзывы: форма с рейтингом, фильтры, пагинация
├── warranty.html       # Гарантия: покрытие, порядок возврата, сроки, FAQ
├── contacts.html       # Контакты: каналы связи, адрес, форма, реквизиты
│
├── css/
│   ├── styles.css      # Дизайн-система + все общие компоненты
│   ├── home.css        # Только главная (герой, схема авто)
│   ├── catalog.css     # Только каталог (сайдбар, фильтры)
│   └── product.css     # Только карточка товара (галерея, buybox)
│
├── js/
│   ├── main.js         # Общее: шапка, меню, подбор, скролл, отправка форм
│   ├── home.js         # Интерактивная схема автомобиля
│   ├── catalog.js      # Фильтрация, сортировка, переключение вида
│   ├── product.js      # Галерея, табы
│   └── reviews.js      # Отзывы: фильтры, пагинация, рейтинг
│
├── images/
│   ├── car-photo.webp  # используется на сайте (109 КБ)
│   └── original/
│       └── car-photo.png   # исходник (2 МБ), в вёрстке не участвует
│
└── design/             # Исходные макеты (.dc.html) — в сайте не используются
```

## Дизайн-система

Токены объявлены в `:root` внутри `css/styles.css`:

| Переменная | Значение | Назначение |
|---|---|---|
| `--blue` | `#1e5cff` | Акцент, ссылки, активные состояния |
| `--orange` | `#ff6a1a` | Целевые действия (CTA) |
| `--dark` | `#0b1730` | Заголовки, подвал |
| `--text` / `--muted` / `--subtle` | — | Три уровня текста |
| `--font` / `--font-d` / `--font-m` | Manrope / Space Grotesk / JetBrains Mono | Текст / заголовки / моноширинный |
| `--nav-h` | `72px` | Высота шапки (нужна для `sticky`-блоков) |

Контент ограничен шириной `1440px`, есть брейкпойнты на `768px` (мобильный),
`769–1024px` (планшет) и `1440px+` (широкий экран).

## Локальный запуск

Сборка не нужна — достаточно любого статического сервера:

```bash
python3 -m http.server 3456
```

Затем открыть <http://localhost:3456>.

## Публикация на GitHub Pages

1. Создать репозиторий и запушить содержимое папки.
2. В репозитории: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` в корне отключает обработку Jekyll — статика отдаётся как есть.

## Как это устроено

Общие блоки — шапка, меню, подвал, нижние табы — одинаковы на всех страницах
и держатся в синхроне вручную: правите один, проверьте остальные.

Формы работают через общий обработчик в `main.js`: любой `<form>` с атрибутом
`data-demo-submit="Текст кнопки"` покажет успех и сбросится через 2,5 секунды.
После сброса форма получает событие `demo:reset` — так `reviews.js` возвращает
звёзды рейтинга в исходное состояние.

FAQ на странице гарантии собран на нативных `<details>/<summary>` — работает
без JavaScript и доступен с клавиатуры.

## Статус

Прототип: данные каталога, товара и отзывов захардкожены в JS, формы не
отправляют запросы на сервер (показывают состояние успеха локально).
